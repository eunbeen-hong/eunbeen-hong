### 🔬 Research
- **FL4N: Feed-forward Latent Model for 4D Novel View Synthesis** (arXiv 2026)
  -  The first feed-forward latent 4D NVS model: renders a dynamic scene at unseen viewpoints and timestamps from a single monocular video, learning temporal dynamics as residuals on a frozen static latent prior
  [[Paper]](https://arxiv.org/abs/2610.35854) [[Project]](https://cvlab-kaist.github.io/FL4N/) [[Code]](https://github.com/cvlab-kaist/FL4N)
- **TETO: Tracking Events with Teacher Observation for Motion Estimation and Frame Interpolation** (ECCV 2026)
  - Teacher-student framework that learns event-camera motion estimation from ~25 min of unannotated real data, then uses the motion to condition a video diffusion transformer for frame interpolation
  [[Paper]](https://arxiv.org/abs/2603.23487) [[Project]](https://cvlab-kaist.github.io/TETO)
- **Seg4Diff: Unveiling Open-Vocabulary Segmentation in Text-to-Image Diffusion Transformers** (NeurIPS 2025)
  — analyzes joint image-text attention in MM-DiT and finds a "semantic grounding expert" layer whose attention maps already yield open-vocabulary segmentation masks; a lightweight LoRA fine-tuning on mask-annotated data (MAGNET) improves both segmentation and generation quality
  [[Paper]](https://arxiv.org/abs/2509.18096) [[Project]](https://cvlab-kaist.github.io/Seg4Diff)
- **S4M: Boosting Semi-Supervised Instance Segmentation with SAM** (ICCV 2025)
  - Integrates SAM into a teacher-student framework via structural distillation, SAM-based pseudo-label refinement, and an instance-aware augmentation, reaching state-of-the-art results on semi-supervised instance segmentation benchmarks
  [[Paper]](https://arxiv.org/abs/2504.05301) [[Project]](https://cvlab-kaist.github.io/S4M)
